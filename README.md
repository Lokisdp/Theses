## Master's research

The master's work investigates estimation of a vehicle's own motion from radar observations. Its technical scope combines Doppler-based speed estimation, Kalman filtering and point-cloud registration, with validation against reference motion.

The current release contains an overview of the research scope and validation plan. Final results and suitable project files will be added after the defence; validation targets are not presented as achieved results.
